# 5. Experimental Findings

## 5.1 Three invariant domains

The monograph tests the recovery principle across three qualitatively distinct invariant domains:

1. continuous Hamiltonian mechanics,
2. discrete topological closure,
3. temporal-causal planning.

Across these settings, the same qualitative pattern appears: standard behavioral retraining restores visible task performance rapidly while leaving boundary discrimination impaired.

## 5.2 Recovery asymmetry

The core empirical result is that behavioral fine-tuning achieves rapid restoration of task execution while leaving TIS substantially lower than the undamaged model. In other words, the system becomes fluent but not deeply grounded.

The manuscript terms this state Coherent Delusion.

## 5.3 Constraint-guided recovery

When post-disruption optimization is paired with a domain-specific invariant regularizer or transitivity objective, the recovery curve changes significantly:

- behavioral competence remains comparable,
- boundary discrimination rises markedly,
- grounded persistence improves substantially.

This is consistent with the null-space intervention hypothesis: the additional guidance moves the system toward the invariant normal directions that are otherwise invisible to ERM.

## 5.4 Null-space intervention result

The null-space consistency update directly tightens boundary rejection while preserving task prediction quality to first order. The manuscript reports that such interventions yield significant gains relative to random null baselines while maintaining lawful-task non-inferiority.
